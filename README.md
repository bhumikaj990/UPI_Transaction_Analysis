# UPI Transaction Analysis Project

# Project Overview
The UPI Transaction Analysis project focuses on analyzing UPI transaction data to understand transaction trends, success rates, failure rates, payment patterns, and customer transaction behavior.

The main objective is to extract meaningful business insights from transaction data using Excel, Python, SQL, and Power BI.

##  Project Objectives
- Analyze overall UPI transaction performance.
- Identify successful, failed, and pending transactions.
- Calculate transaction success and failure rates.
- Analyze city-wise and bank-wise transactions.
- Identify transaction trends and patterns.
- Generate meaningful business insights.
- Create an interactive Power BI dashboard.

# Tools & Technologies Used

 Tool 

| Microsoft Excel - Data cleaning and initial analysis 
| Python - EDA and visualization 
| Pandas - Data manipulation and analysis 
| Matplotlib & Seaborn - Data visualization 
| MySQL - SQL queries and business insights 
| Power BI - Interactive dashboard and reporting 


# Project Workflow

1. Data Collection – Collected UPI transaction dataset.
2. Data Cleaning – Identified and handled missing values and duplicate records.
3. Exploratory Data Analysis (EDA) – Analyzed transaction patterns using Python.
4. SQL Analysis – Performed SQL queries to extract business insights.
5. Data Visualization – Created charts to understand transaction trends.
6. Dashboard Development – Built an interactive Power BI dashboard.

# Key Business Insights

- Overall transaction success rate: 88.3%.
- Transaction failure rate: 7.7%.
- Mumbai was identified as the top city based on transaction activity.
- Axis Bank was identified as the leading bank based on transaction activity.
- Transaction status analysis helped understand successful, failed, and pending payments.

# Power BI Dashboard

Dashboard highlights:
